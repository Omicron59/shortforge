# Workflows ComfyUI

- `image_default.json` : exemple d'image verticale SDXL (modèle `sd_xl_base_1.0.safetensors` attendu dans ComfyUI).
- Les moteurs vidéo locaux cherchent un workflow portant leur identifiant : `wan22_local.json`, `ltx_video_local.json`, `cogvideox_local.json`, et `comfyui_local.json` pour le moteur ComfyUI générique.
  Exporte-les depuis les modèles de ComfyUI avec « Workflow → Export (API) », puis ajoute-les depuis l'application ou dépose-les ici avec leur fichier `.shortforge.json`.

Voir [COMFYUI_WORKFLOWS](../../docs/COMFYUI_WORKFLOWS.md).
